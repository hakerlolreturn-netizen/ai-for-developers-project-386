# Страницы владельца открыты без входа

Владелец в сервисе один и задан заранее, поэтому аутентификации нет: управление типами встреч и список предстоящих встреч доступны любому, кто знает адрес. Это осознанное упрощение учебного проекта, а не пропущенная защита; вход появится только вместе с поддержкой нескольких владельцев.
