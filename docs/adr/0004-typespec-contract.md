# Контракт API описывается в TypeSpec

Контракт API пишется в TypeSpec, а OpenAPI-спецификация генерируется из него и вручную не правится. TypeSpec короче и строже OpenAPI в YAML, а сгенерированный OpenAPI остаётся общим форматом для инструментов бекенда и фронтенда. Общие типы TypeScript без отдельного контракта отвергнуты: они не дают описания API, которое читается вне кода.
