# Запись на звонок

Упрощённый сервис бронирования времени по мотивам Cal.com: гость записывается на звонок к владельцу календаря.

## Язык

### Участники

**Владелец**:
Единственный хозяин календаря, заданный заранее; заводит типы встреч и видит предстоящие встречи.
_Avoid_: администратор, хост, пользователь

**Гость**:
Человек, который записывается на встречу без регистрации.
_Avoid_: клиент, посетитель, пользователь

### Запись

**Тип встречи**:
Шаблон звонка, заведённый владельцем: идентификатор, название, описание и длительность.
_Avoid_: услуга, событие, event type

**Слот**:
Свободный интервал времени длиной в длительность выбранного типа встречи, который начинается на шаге стартов и целиком лежит в рабочих часах рабочего дня; на него гость может записаться.
_Avoid_: окно, ячейка, таймслот

**Встреча**:
Занятый гостем слот конкретного типа встречи.
_Avoid_: бронирование, запись (как существительное), booking; «встреча» в значении «тип встречи»

**Предстоящая встреча**:
Встреча, которая ещё не закончилась, включая идущую сейчас.
_Avoid_: будущая встреча, активная встреча

**Рабочие часы**:
Интервал времени рабочего дня, в пределах которого владелец принимает встречи; одинаков для всех рабочих дней.
_Avoid_: расписание, доступность

**Рабочий день**:
Будний день, с понедельника по пятницу, в часовом поясе владельца. В субботу и воскресенье встречи не принимаются.
_Avoid_: будни, рабочая дата

**Шаг стартов**:
Интервал между соседними возможными началами слотов, общий для всех типов встреч; отсчитывается от начала рабочих часов.
_Avoid_: шаг сетки, гранулярность

**Окно записи**:
Период, на который гость может записаться: сегодня и следующие 13 календарных дней.
_Avoid_: горизонт, период бронирования

**Часовой пояс владельца**:
Единственный часовой пояс, в котором заданы рабочие часы и показывается всё время в сервисе.
_Avoid_: таймзона, локальное время
